# Jericho Santos Magdangal - Virtual Assistant Portfolio

## How to open
1. Extract the ZIP file.
2. Open the `Jericho-VA-Portfolio` folder.
3. Double-click `index.html`.

## Included projects
- VA Order Management & Sales Tracking Spreadsheet
- VA Task Management & To-Do Tracker

The Excel files are included in the project folder and can be opened with Microsoft Excel.
